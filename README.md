# 🌙 Baby Sleep Tracker

A simple, single-file web app to track a baby's naps, night sleep, and awake time.

**Live app:** https://45dimitarivanov-maker.github.io/baby-sleep-tracker/

## Features

- **Quick sleep entry** — Night/Nap toggle with "fell asleep" / "woke up" times and one-tap **Now** buttons. Sleeps that cross midnight are handled automatically.
- **Daily dashboard** — Total sleep, awake time, night sleep, and day naps for any day, with day-to-day navigation.
- **Editable sleep log** — Edit or delete any logged sleep inline.
- **Awake windows** — See how long the baby was awake between each consecutive sleep.
- **Statistics** — Daily averages over the last 3 / 7 / 14 / 30 days.

## Privacy

All data is stored in your browser's **localStorage** — nothing is sent anywhere. It stays on the device you use.

## Running locally

Just open `index.html` in any modern browser. No build step, no dependencies.
